# Flatland.jl

A Julia implementation of the [Flatland](https://github.com/flatland-association/flatland-rl) railway simulator, which
lives next to the Python package `flatland-rl` in the same repository.

The Python package is the reference implementation. This package aims at reproducing its trajectories exactly and at
simulating them much faster, with a thin Python wrapper so that existing Python code can use it. The plan is in
`REVAMP.md`, at the root of the repository.

!!! warning
    Work in progress: nothing can be simulated yet.
